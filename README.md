# What Is This Repository?

This repository is a end-to-end data analysis using Airbnb listing data sourced from Inside Airbnb. The project covers the complete analytics workflow including: data acquisition, cleaning, exploratory data analysis, visualization, and business reporting. The analysis was designed around three business questions: 

1. Which property types appear to have the strongest demand based on review volume?
2. What listing characteristics are associated with higher guest demand?
3. How does pricing influence occupancy?

The business report includes information about what conclusions were made. If you would like to read the code please see "Airbnb-Analysis.ipynb". Also, I left comments throughout the code. Though, the code is quite self-explanatory and the business report really covers up any confusions or questions you may have of the data.
